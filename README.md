# Finnish-School-Python
## What is Python?
**Python** is a programming language we use to write instructions for computers and robots.
## Why do we use Python with mBot2?
We use Python to tell mBot2 what to do. For example, we can tell it to show a message on its screen or change the color of its lights.
## What is a Python comment?
A python comment is a *note* that helps people understand the code. It starts with `#`, and Python skips the rest of that line.
## Why do we display text on a screen?
We display text so people can see messages and results from the program. For example, mBot2 can show a welcome message when the program starts.
## Three simple Python examples
1. Write a comment.
2. Store a number in a variable.
3. Print a message.
~~~python
# This is a comment
grade= 11
print("Hello, ICT!")
~~~
